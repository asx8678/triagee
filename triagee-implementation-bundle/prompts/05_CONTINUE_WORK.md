# Continuation prompt for a new session/agent

Continue the Triagee action-first implementation from the existing checkout and latest implementation report. Read START_HERE, the master prompt, precedence document, tasks.json, applicable repository instructions, and the last milestone report.

Inspect HEAD, uncommitted changes, and actual test evidence. Determine the first unfinished task whose dependencies are complete. Verify claimed prior work rather than resetting, rebuilding a second app, or repeating a broad planning exercise. Preserve unrelated work, current schema/readers, drafts, and pending ticket claims.

Before tests, identify owned database/process resources from current repository guidance; never assume ownership of another session's environment. Re-run relevant checks when evidence is stale or code changed. Continue the next bounded task, with real implementation and tests. Record progress, exact blockers, safety constraints, and the next task in the report. Do not treat a historical PASS as current certification.
